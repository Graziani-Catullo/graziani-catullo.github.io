# Pagina di avvio — Gestionale Graziani Catullo

Pagina pubblica che serve solo ad aprire il gestionale dal telefono:

- logo sulla schermata Home (icone per iPhone e Android);
- il gestionale a schermo intero, dentro la pagina;
- ricorda la chiave d'accesso sul telefono, così non si rifà il codice a ogni apertura.

Qui **non ci sono dati**: per entrare serve sempre il codice mandato all'email di un utente del gestionale.
La chiave si scambia solo con le cornici di Google Apps Script aperte dentro questa pagina.

`?app=prova` apre il link di prova invece di quello ufficiale.
